# 280 条／30 秒 `mixed_pressure` 单次实测

用户要求的“四倍请求数且四倍时间压缩”现已按字面实现：70 条原始多模态请求各复制四份，唯一请求 ID，所有计划到达时刻除以四。总计 **280 条／30 秒**，计划平均到达率是原来的 **16 倍**；只包含 70 种不同输入内容。旧版 70 条／30 秒仅压缩到达时间，保留为历史试验。

实机运行使用干净提交 `df900a6a`，与旧版的 641 个运行时 Python 文件哈希相同；固定工作树中另一对话的未提交控制器改动未进入服务。280 条均实际发送：170 成功、110 在原有 240 秒客户端安全截止时超时。Talker KV 池峰值 100%，原生占用 >90% 的已观测时间约 198 秒，出现 **18 次真实分配失败、18 次被动抢占**；旧版 70 条／30 秒单次运行是 2 次。18 个 victim 均有实际 KV 释放，最终也都超时，且无完整恢复事件。不能因此把 110 个超时都归因于抢占。服务健康排空，但发生在客户端超时取消后。
